Create HTML Artifact
流程与规范

交付物永远是一个能从磁盘直接打开的 .html——可移动、可邮寄、可单独分享。角色是小型工作室 的 design lead：每个交付物按任务选 treatment，有专属调色、字体与版式，而不是套模板。本页本身就是该 skill 的产物。

触发 本地 HTML 页面 / 报告 / 演示 / 落地页 不做 上线托管 · 多文件站点 · 带独立 build 的 app 交付 文件路径，不是 URL

一句话

先写body fragment（内容 + 自己的 <style> / <script>），再用捆绑脚本 scripts/build.py 注入骨架，得到单文件完整文档。先校准 treatment，再定 token，再写代码；交付前扫一遍本地相对路径。

优先级

用户原话 → 项目已有设计系统 → 你的选择。已有系统只填空、不覆盖。

01

读请求，校准 treatment

争论的不是「要不要设计」，而是用哪一档 treatment 交付设计。文档与落地页同等认真；差别在火力与姿态。

utilitarianeditorial
02

写设计计划（再写代码）

紧凑 token 系统：4–6 个命名色；至少两种字体角色；一两句话的 layout 概念。之后每个颜色与字体决策都从计划导出。

ColorTypeLayout
03

写 fragment，不是完整文档

只写页面内容：markup + 自有 style/script。禁止手写 <!doctype>、<html>、<head>、<body>——build 会注入，且含骨架的输入会被拒绝。

fragment.html
04

用 build.py 打包

脚本包完整骨架、最小 CSS reset（含 color-scheme: light dark）、钉死版本的 Mermaid CDN 与主题感知 init。

python3 scripts/build.py
05

核对可移植性并交付路径

扫 src=、href=、url( 是否指向本地相对路径。有命中 = 未完成。把文件路径交给用户——不是 URL、不是上传。

page.html
# 典型调用
python3 scripts/build.py fragment.html -o page.html \
  --title "可选标题" --lang zh-CN
# --title 缺省时取第一个 <h1>；再缺省用输出文件名

输出契约（硬门）

成品是单一完整 HTML。契约用允许 / 禁止写清，避免「看起来像做完了」。

允许 可移植单文件

  • 恰好一个 .html
  • 样式与脚本写在 fragment 内
  • 本地/生成图用 data: URI
  • 库、网页字体、远程图走 CDN，并钉版本
  • <pre class="mermaid"> 开箱即渲染
  • CDN 不可达时，图源以纯文本可见（降级）

禁止 破坏契约

  • 手写完整文档骨架（doctype/html/head/body）
  • 指向兄弟文件的相对路径（如 ./img.png、styles.css）
  • 上传、托管、发布页面
  • 交付 URL 代替文件路径
  • 多文件站点或带独立 app build 的工程
  • 未钉版本的 CDN（页面随上游漂移）

build.py 注入了什么

skeleton
<!doctype html>、<html lang>、charset、viewport、title
CSS reset
box-sizing、color-scheme、body margin、媒体 max-width、表单 inherit 等
Mermaid
钉死的 jsDelivr mermaid@11 + 按 data-theme / prefers-color-scheme 选 dark/default

单主题例外

reset 默认 color-scheme: light dark。若页面刻意只活在一个视觉世界（霓虹街机、凸版请柬），可覆盖为单主题——这是选择，不是遗漏。

校准 treatment

同一套工艺，不同火力。不确定时：写好的版面永远没错；过度包装的视觉身份有时会错。

多数请求

Utilitarian

计划、备忘、报告、demo。真层级、真间距、真调色——但不堆花活。多数页不需要闪烁 hero；点缀克制、有限。

少数请求

Editorial

落地页、游戏、用户会留存或分享的工具。客户已经拒绝「像模板」的方案。做有观点的选择，并在服务内容的前提下承担一处真实美学风险。见下文专节。

设计计划：写代码前的 token 系统

本页的计划示例（meta：说明 skill 时也按 skill 做）：

Color

Ink · Paper · Registration teal · Build amber · Forbid · Allow——排版工作室 / 打样间气质，避开 AI 默认奶油陶土与酸绿黑底。

Type

Fraunces — display Public Sans — body JetBrains Mono — code / labels

有性格的 display 克制使用；body 互补；工具面用 mono。

Layout

粘性目录 + 单栏可读正文；契约用允许/禁止对板；流程用编号序列（内容本身是步骤序列，编号信息而非装饰）。

每页都成立的规范

下列是 fundamentals——无论 utilitarian 还是 editorial，都要从这里出发。

Ground it in the subject

钉死主体、受众、页面唯一工作。材料、工具、行话来自主体世界。全文用真实内容，永不 lorem。

Pair typefaces

CDN 加载并钉族/字重/子集；本地 fallback 写好。正文约 65 字符宽；固定 type scale；标题 text-wrap: balance；大写标签略 letter-spacing。

Choose neutrals

纯中灰像没想过；略向 accent 偏的灰才像选过。纯白 / 近黑可以，前提是故意选的。

Design both themes

token 定义在 :root，只在 dark media query（或 data-theme）重定义 token。组件只吃 token，不进 media query 写死。第二主题同等用心，禁止naive invert。

Layout does spacing

兄弟组用 flex/grid + gap，不用互相塌缩的 margin。宽表/代码/图自带 overflow-x: auto。图 max-width: 100%。对齐数字用 tabular-nums。

Build cleanly

注意重叠、层叠打架、静默字体回退。闭合标签、双引号属性、可见 focus、尊重 prefers-reduced-motion。装饰图形优先 Canvas/WebGL，别手搓超长 SVG path。

Copy is material

用用户认得的名字（通知，不是 webhook config）。主动语态；控件说清会发生什么。错误说明原因与修法——不道歉、不模糊。具体胜过俏皮。

Structure is information

编号、eyebrow、分割线、标签必须编码真实结构，不是装饰。01/02/03 仅当内容真是序列时才用。

UI ≠ document

仪表盘/工具是扫读与操作：摘要先于细节；状态用 pill/chip/severity 编码；语义色（好/警告/危）与 accent 分离；交互看起来像可交互。

Watch specificity

类型选择器与元素选择器别互相取消 padding/margin。整理 cascade，避免静默撤销间距。

主动避开的 AI 默认脸

用户指定某一种时照做；未指定时不要把自由度花在这些默认上：

  • 暖奶油底 (#F4F1EA) + serif display + 陶土 accent
  • 近黑底 + 单点酸绿 / 朱红
  • 大报 hairline + 密栏
  • 白底紫→蓝渐变 hero
  • Inter / Space Grotesk 当「安全脸」
  • emoji 当章节标记；全局居中；处处 rounded-lg；圆角卡左侧 accent 条

Editorial：何时加火力

姿态切换：客户已拒绝模板感，并为鲜明观点付费。做有意见的决定；在服务作品的前提下承担一处真实美学风险。

动工前自检

对照主体审设计计划：任何一段读起来像「给任意同类页的通用默认」，就改掉，并记下改了什么、为什么。然后再写代码，严格跟修订后的计划。

原则 做法
Hero 是 thesis 用主体世界里最有特征的东西开场——标题、图、实时 demo、交互瞬间
字体承载个性 刻意配对，不是「任何项目都会用的那对」；字处理本身要难忘
运动克制有意图 入场、滚动揭示、hover、氛围——通常一处编排强过散点；多余动画本身是 AI 痕迹
复杂度匹配愿景 极繁要执行到位；极简要靠间距、字体与细节精度。优雅 = 把选定愿景做对
胆色花在一处 周围保持安静。accent 与底打架时，往类似色移或降饱和，而不是乱换 hue

交付前核对

契约未过 = 未完成。下面是可执行清单：

输入是 fragment：无 <!doctype> / <html> / <head> / <body>
经 build.py 产出完整单文件；title / lang 合理
扫 src=、href=、url(：无指向本地相对路径（锚点 #… 与 CDN 可）
本地资源内联；CDN 已钉版本；字体有本地 fallback
双主题 token（或刻意单主题）；light/dark 对比与 accent 都可读
treatment 与请求匹配；设计计划 → 实现一致；非 AI 默认脸（除非用户点名）
交付物是路径；未上传 / 托管 / 发布

交付句式

「成品在 path/to/page.html，用浏览器打开即可。」——路径即交付，解释流程是加分，不能替代路径。
